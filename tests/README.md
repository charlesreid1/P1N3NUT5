# tests/

Pytest suite. Parsers + fake-transport tests only — no live radio,
no live Pineapple. Fixtures under `tests/fixtures/` are small, named,
and generated by `scripts/generate-pcap-fixtures.py` so the corpus
stays deterministic. 857 tests pass in under a second.

## Modules

- **`test_adversarial_corpus.py`** — corpus-shape defenses (dupe ids,
  malformed era_bounds, missing citations).
- **`test_attacks.py`** — SSH-fake tests for `deauth`, `capture_*`,
  `create_rogue_ap`, `stop_rogue_ap`, `evil_twin`; PMF-required
  refusals; airspace-authorization gating.
- **`test_coverage_matrix.py`** — every capability in
  `CAPABILITY_RULES` has a real code path in `server.py`. Fails loud
  when the transport table and the MCP tool inventory drift apart.
- **`test_depth.py`** — the D1–D5 authoring floors (attacks ≥ 90,
  frames ≥ 30, IEs ≥ 80, EAP methods ≥ 30, hashcat modes ≥ 30,
  endpoints firmware_min 100%). This is the depth CI-gate.
- **`test_detect.py`** — pcap parsing, handshake extraction
  (M1/M2/M3/M4 completeness), PMKID extraction, byte-level 802.11
  frame walk.
- **`test_fixture_pcaps.py`** — round-trip through every fixture pcap;
  every record with `flag_signature` has a matching fixture.
- **`test_gold_corpus.py`** — the gold-standard Q/A pairs; assistant +
  MCP must answer each correctly against the loaded records.
- **`test_hashcat.py`** — mode 22000 conversion round-trip against
  fixture pcaps + parsing of `WPA*TYPE*...` lines.
- **`test_knowledge_tools.py`** — `lookup_*`, `verify_claim`,
  `explain_attack`, `bibliography`, `cross_reference`, `search_records`
  against the loaded corpus.
- **`test_orchestrate.py`** — end-to-end scripted engagement in
  fake-transport mode (recon → capture_handshake → convert_to_hashcat
  → crack_start).
- **`test_pineapple_status.py`** — API and SSH status flow with
  injected fakes.
- **`test_recon_normalize.py`** — 3.0 vs 3.1 firmware payload shape
  normalization for APs / clients / probe requests.
- **`test_recon_pineap_tools.py`** — MCP-tool-layer smoke tests for
  recon and PineAP.
- **`test_records_loader.py`** — every JSON record file round-trips
  through schema validation; every `citations[]` entry resolves; every
  `see_also` resolves; `era_bounds` well-formed everywhere.
- **`test_runtime.py`** — `Config.from_env` env-var handling,
  `require_api` / `require_ssh` credential checks, transport-pref
  validation.
- **`test_transport_choice.py`** — capability → transport resolution,
  including env-pref override and unsupported-transport refusal.

## Fixtures

- `tests/fixtures/pcaps/<record-id>.pcap` — one small pcap per
  Tier-1 attack record and per frame_types record. Keyed by record
  id so records and fixtures move together.
- `tests/corpus/` — canned expected-answer traces for the gold Q/A
  pairs.
