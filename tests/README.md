# tests/

Pytest suite. Parsers + fake-transport tests only — no live radio,
no live Pineapple. Fixtures under `tests/fixtures/` are small, named,
and generated by `scripts/generate-pcap-fixtures.py` so the corpus
stays deterministic.

Phase 0 has authored none of the tests below. Same shape as
PHR34CKER5's `tests/`.

## Planned

- **`test_records.py`** — every JSON record file under
  `knowledge/records/` round-trips through schema validation, every
  `citations[]` entry resolves to a `bibliography.json` id, no
  orphaned bib records, `era_bounds` well-formed everywhere.

- **`test_pineapple_api.py`** — REST transport against a fake WebUI
  backend: status/recon/pineap/module endpoints, structured error
  paths, bearer-token auth-scope enforcement, per-firmware payload
  shape assertions from `records/pineapple_endpoints.json`.

- **`test_pineapple_ssh.py`** — SSH transport against a fake asyncssh
  server: command whitelist, call_log capture, timeout handling.

- **`test_detect.py`** — pcap parsing, handshake extraction (M1/M2/
  M3/M4 completeness), PMKID extraction, IE decode, beacon_diff.

- **`test_hashcat.py`** — mode 22000 conversion round-trip against a
  fixture pcap.

- **`test_qa_corpus.py`** — the ~100 gold-standard Q/A pairs from
  plan-knowledge.md § "Build/populate plan"; assistant + MCP must
  answer each correctly.

- **`test_verify_claim.py`** — the ~40 trap questions from
  plan-knowledge.md § "Explicitly disputed / ambiguous entries";
  `verify_claim` must return `false` or `needs_qualification` with a
  citation to the correct record.

- **`test_run_sequence.py`** — end-to-end scripted engagement in
  fake-transport mode, covering the example from plan-organize.md
  (recon → capture_handshake → convert_to_hashcat → crack_start).

## Fixtures

- `tests/fixtures/pcaps/<record-id>.pcapng` — one small pcap per
  Tier-1 attack record and per frame_types record. Keyed by record
  id so records and fixtures move together.
- `tests/fixtures/api/*.json` — canned WebUI responses per firmware
  version, keyed by endpoint id.
- `tests/fixtures/ssh/*.txt` — canned command outputs (`iw dev`,
  `hcxdumptool`, `airodump-ng` CSV).
